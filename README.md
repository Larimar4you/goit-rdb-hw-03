# goit-rdb-hw-03

Домашнє завдання до теми 3  
**«Завантаження даних та основи SQL. DQL команди»**

## Виконані завдання

1. Вибір усіх даних із таблиці `products`
2. Вибір стовпчиків `name` та `phone` із таблиці `shippers`
3. Обчислення середньої, максимальної та мінімальної ціни товарів
4. Вибір унікальних значень `category_id` та `price` із сортуванням за спаданням
5. Підрахунок кількості продуктів у ціновому діапазоні від 20 до 100
6. Підрахунок кількості продуктів та середньої ціни для кожного постачальника
